Three-file static site with no build step: `index.html` is the single entry point that loads `css/style.css` (design tokens → reset → reusable pieces → per-section styles → responsive rules) and `js/script.js` at the bottom of `<body>`. The stylesheet follows a top-to-bottom section order mirroring the HTML markup. The script is wrapped in an IIFE with strict mode and exposes only two helpers (`$`, `$$`) — all behavior (sticky header, mobile hamburger menu, active-nav tracking via `IntersectionObserver`, reveal-on-scroll, animated skill bars, counting numbers, typing effect, form validation, back-to-top, dynamic footer year, mouse-follow glow) is organized as numbered feature blocks inside that closure. There are no frameworks, libraries, or external dependencies beyond Google Fonts; interactivity is entirely DOM manipulation plus CSS class toggling.
